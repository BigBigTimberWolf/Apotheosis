# 最初 AVA 控制链研究

2026-09-28。研究基准为 Git 提交 `d51e389`（2026-07-24），即仓库最早加入 `ava_exact/pidf_mode1_exact.cpp` 的版本。后续 9 月的 D 低通、Smith、延迟调度等修改不混入本次结论。本轮仅静态阅读源码及代数推导，不运行测试，不修改或编译生产算法。

这是对历史移植源码的研究，不代表本轮重新验证了 AVA 原始二进制，也不构成全部参数、延迟下的稳定性证明。

## 1. 当时实际运行哪一套

`boss_aim.cpp:139` 固定选择 mode1；Ki 在接入层强制为 0；Process/QX 关闭，项目自己的 AimPath 在 PIDF 后面整形。mode2 虽保存在仓库中，并非这条接入路径的运行模式。通用 `pidf_update_exact.cpp` 也不能代替实际调用的 mode1 理解数值。

历史 UI 参数实际对应：Kp=瞄准速度，Kd=过冲控制，Kf=锁定强度，LR=预测速度。尤其 **LR 是状态学习率，不是目标速度，也不是预测帧数**。历史配置允许 LR 到 99.99，不能无条件将它视为 0～1 的平滑系数或断言它总是稳定。

## 2. 一帧的真实顺序

1. 跟踪器接收检测框，校正卡尔曼状态，再预测一个离散步，生成用于选点的跟踪框。
2. 从该框生成瞄点，计算基础误差 `e = aim - cross`。
3. 使用上一帧跟随状态、框尺寸与方向判断，计算高 Kf 的位置修正；将其加到误差，形成 `E`。
4. 根据 `E` 与框尺寸更新当前高斯权重、历史最大权重及动态学习率。
5. P/I/D 都使用 `E`；普通 PID 部分稍后乘 0.1。
6. 用 `E` 的变化、上帧整数输出和已有跟随状态更新低 Kf 通道；其输出单独加到普通 PID 上。
7. 分帧缩放、整数余量、轴屏蔽、死区和移动限幅产生本帧整数输出。
8. 必要时衰减积分与跟随状态；保存本帧误差、时间和整数输出，供下一帧使用。

这里高 Kf 的位移先改变误差，改变后的误差又参与跟随状态更新。各部分不是互不相关的独立插件。

## 3. 两种“预测”不是同一状态

### 跟踪框卡尔曼

`target_tracker_exact.cpp` 保存 `[x,y,vx,vy]`，状态转移中的时间步固定为 1。测量是检测中心；更新后 `build_output()` 调用一次 predict，输出中心还有以最近检测中心、框尺寸和 search_radius 为依据的范围限制。

速度是每次更新对应的图像位移。跟踪器的速度没有直接传给 PIDF 的 `ff_state`；PIDF 从误差和自身输出另外更新状态。该预测并不是面向用户的 N 帧外推开关。

丢帧至少 2 帧时有 origin_offset 修正分支，但本项目的 `boss_aim.cpp` 调用传 `{0,0}`，不能把它解释成当前接入已有精确的相机运动补偿。`predicted_center_valid=0` 也不表示没有预测：预测后的框本身已被用于选点。

### PIDF 跟随状态

mode1 的核心原式：

```text
predicted_minus_move = v_old * dt + E_previous - u_previous
innovation          = E_current - predicted_minus_move
v_new               = v_old + alpha * innovation / dt
feed                = v_new * dt * min(Kf, 1)
```

`alpha = LR * 当前高斯权重`。`u_previous` 是该 PIDF 上一帧在死区/限幅之后的整数输出。它没有等待驱动报告成功，也没有把后续轨迹整形和图像传输延迟逐项对齐。源码没有显式的“计数→像素”标定系数；这也不意味着 v 是准确目标像素速度。

## 4. 为什么 Ki=0 仍能补持续落后

为了看清机制，暂作以下简化：固定 dt，Kf=1，高 Kf 修正关闭，近点权重约为 1，不触发反向衰减、量化、死区、限幅或分帧缩放，I/D=0，alpha 近似固定。令 `q = v * dt`，`k = 0.1*Kp`，则：

```text
q[n] = (1-alpha)*q[n-1] + alpha*(e[n]-e[n-1]+u[n-1])
u[n] = k*e[n] + q[n]
```

代入上一帧输出可得：

```text
q[n]-q[n-1] = alpha*(e[n]-e[n-1]) + alpha*k*e[n-1]
```

再令 `J[n] = q[n] - alpha*e[n]`：

```text
J[n] = J[n-1] + alpha*k*e[n-1]
u[n] = (k+alpha)*e[n] + J[n]
```

**这个简化区域内，它具有 PI 式的积分作用，即使显式 Ki 为 0。** 因此它可以逐步形成维持跟随所需的输出，而非必须先精确测出目标物理速度。实际算法还有动态权重和非线性，不能把完整 AVA 直接等同于普通 PI。

当 Kf<1 时，简化式中 q 的自身保留系数变为 `1-alpha*(1-Kf)`，存在泄漏；Kf=1 时对应无泄漏的简化形式。加入输出权重 W 和分帧缩放 S 后，实际回注系数为 `S*W*min(Kf,1)`。这解释了低 Kf 通道的设计，但不能独立证明整个闭环稳定，尤其 alpha 可能大于 1。

## 5. Kf 超过 1 后的位置修正

源码拆为 `Kf_low=min(Kf,1)` 和 `Kf_high=max(Kf-1,0)`。低 Kf 部分不会随着 Kf>1 而继续线性增大。

高 Kf 部分每轴使用旧跟随状态 q，以及 `r=min(框宽,框高)`；变量虽名 radius，这里传入的是框尺寸的较小值，不应误当半径再除 2：

```text
t = tanh(abs(q)/(0.05*r+epsilon))
candidate = ((sign(q)*r-q)*t + q)*Kf_high
correction += alpha_high*(candidate-correction)
E = e + gaussian_high(e,r,direction)*correction
```

这是向框尺寸相关偏移过渡的非线性、带记忆的修正，不是 `速度*N*dt`。也不能说它严格限幅在一个框内：Kf_high 可大于 1，公式本身不是硬裁剪。

mode1 的学习率和修正施加都受高斯权重影响；正常尺度约为 1.5r，高 Kf 修正阶段约为 0.5r，状态与误差反向时约为 0.25r。高 Kf 先修正 E，后续低 Kf 更新又读取 E，所以不能只抽出 candidate 当成独立外推器。

## 6. 被上次实现遗漏的配套

- **输出位置与倍率：** mode1 为 `S*(0.1*PID(E) + W*dt*v_new*Kf_low)`。跟随量直接加到输出，不再额外乘一次 Kp。当前原 PID 则有自己的分段及增益；系数不能直接互换。
- **学习门控：** 当前高斯权重控制学习，误差大时学习减弱。9 月提交加的权重下限不属于最早版。
- **输出权重有记忆：** W 为历史最大高斯权重，不等于当前高斯权重；即使 Ki=0，也会参与前馈施加。不能简单声称“离远就立即关闭全部前馈”。
- **反向衰减：** 积分或跟随状态与当前误差方向相反时，按高斯权重衰减状态。这不是目标静止识别器，也不是无条件归零。
- **死区停止：** 原始误差进入死区且该轴整数输出绝对值≤1时才清零。它不是当前原 PID 那种保留最低比例的连续死区衰减。
- **生命周期：** 新目标、丢目标和配置重建会重置相应 PIDF 状态，首次有效帧初始化但不输出。

## 7. mode2 的差别

mode2 具有同样的低 Kf 状态更新及高 Kf 非线性候选，但学习率同时依赖运动方向与误差；高 Kf 修正直接加到误差，未使用 mode1 同样的施加高斯包络。离目标超过 1.5r 时会清积分权重、积分和跟随状态；反向衰减采用另一条 tanh 公式。mode2 输出没有 mode1 的 frame_scale。不能将 mode2 的这些条件混称为本项目最早运行的 AVA 行为。

## 8. 与本次失败实现的具体差别

| 项目 | 最早运行的 AVA mode1 | 当前失败的提前帧方案 |
|---|---|---|
| 跟随状态更新 | 动态 LR，读取修正误差和上次 PIDF 输出 | 位置/速度卡尔曼，读取检测中心和成功发送累计量 |
| 跟随状态回注 | 低 Kf、输出权重、分帧系数后直接加输出 | 乘 N*图像间隔，加到瞄点，再经过原 P/I/D |
| 更强的位置修正 | Kf>1，框尺寸参与的非线性和平滑、门控 | 整个范围都按帧数线性放大 |
| 反向处理 | 有方向相关学习/状态衰减 | 无对应机制，只有大残差重置 |
| 时序约定 | 本地 update dt 与上一帧整数命令 | 图像回调时间与成功发送时间配对，未校准画面内部延迟 |

仅看纯 P，当前方式就引入了约 `Kp/segment * N*dt*v` 的新增输出，不同于 AVA 的 `S*W*Kf_low*dt*v`。所以 I/D/FF 都设 0 也不意味着整个系统只剩纯 P：预测模块本身已带状态反馈。

自身输出参与预测并非天然错误；若观测模型匹配，它可以补偿相机运动。**能从源码确认的是两种闭环不等价**，不能在没有同步实机记录时断言抽搐全部由某一个比例或延迟造成，更不能声称搬回一个门控就已修好。

## 9. 对后续设计的约束

用户希望原 PID 不改、0 帧保持原行为、只调一个提前参数。这不是最早 AVA 现成提供的接口。

若借鉴 AVA 的经验跟随补偿，必须连同状态更新、回注位置、有效增益、方向处理一起设计；这样的旋钮首先是补偿强度，不能未经证明就标成准确的未来 N 帧。

若坚持位置外推的帧数语义，则需要可靠的位置运动观测及自身运动处理。可以探索内部估计或图像运动信息，不意味着必须要求用户手填标定参数；但仅替换一个滤波器或将鼠标计数直接相加不能保证满足需求。

下一次实现前应先确定完整公式和零值等价性，而不是继续把经验跟随状态视为真实目标速度。此次研究不修改现有算法，也不把未运行测试的推导写成已验证的修复。
