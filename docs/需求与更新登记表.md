# Apotheosis 需求 / Bug / 更新日志（单表模板）

在线表：腾讯文档《需求bug描述》。**只有一个工作表**，用区块竖排；每个区块一种颜色；版本号是全表的连接键。

## 区块与配色

| 区块 | 颜色 | 列 |
|---|---|---|
| 公告 | 橙 | 版本号 / 日期 / 级别 / 标题 / 用户要做 |
| 更新日志 | 蓝 | 版本号 / 日期 / 类型 / 模块 / 变化 / 用户要做 / 提交 |
| 版本索引 | 紫 | 版本号 / 日期 / 类型 / 条数 / 修复 / 新增 / 强制升级 / 提交 |
| Bug登记 | 红 | 编号 / 状态 / 提交人 / 日期 / 版本 / 模块 / ＊现象与复现步骤 / 结论 |
| 需求登记 | 绿 | 编号 / 状态 / 提交人 / 日期 / 版本 / 模块 / ＊需求 / 优先级 / 结论 |
| 历史登记 | 灰 | 需求/bug描述 / 提交时间 / 完成时间（原表 33 条，2026-10-05 原样迁移） |

第 1 行是深蓝底白字的表标题。区块标题行 = 中调色 + 加粗；表头行 = 同色淡调 + 加粗；数据行白底。

## 版本号

`v主版本.次版本.修订号`：修订号=修复，次版本=新增功能或配置键，主版本=需要重新配置或重新标定。
发布一个版本：更新日志加行 → 公告写一条 → 版本索引加一行 → 关闭同版本 Bug。
