# DXGI 屏幕截图

直接读取显卡正在输出的桌面画面作为采集来源，不需要采集卡，也不需要 OBS / NDI。

## 怎么用

采集设置 → 采集来源选 **DXGI · 屏幕截图（无需采集卡）** → 在“显示器”里选要截取的屏幕（默认“主显示器（自动）”）。送去检测的是该显示器**正中心的正方形**，边长等于检测分辨率，和其他采集来源一致。显示器被拔掉时设置里仍会保留你选的那一项（标成“未连接”），运行时自动改用主显示器并在日志里提示。

配置文件里对应 `capture_source = dxgi` 和 `capture_dxgi_output`（显示器设备名，如 `\\.\DISPLAY1`，留空为主显示器）。

## 限制

- **独占全屏的游戏可能截不到**，请改用无边框窗口化。
- **HDR 显示器、旋转（竖屏）的显示器暂不支持**，会在日志里明确提示，不会硬截一张错的画面。
- 画面里没有鼠标指针。
- 画面来自显示器所连接的那块显卡；多显卡电脑选哪块屏就用哪块卡。
- 屏幕没有更新时不会产生新帧（静止画面不出帧）；游戏运行时屏幕一直在更新，不受影响。
- 锁屏、UAC、切换分辨率会让截取暂时中断，程序会自动重试恢复；持续约一分钟都不行才会放弃并在日志里说明。
- 延迟取决于显卡和系统的桌面合成，需要你在自己的机器上实测，和采集卡直连相比没有现成的对比数据。

## 实现说明

平台无关的判断集中在 `capture/dxgi_capture_logic.h`（显示器选择、居中裁剪、时间戳换算、像素转换、帧率估计、失败恢复策略），有单元测试 `dxgi_capture_logic_test`；`capture/dxgi_capture.cpp` 是很薄的一层 Windows 桌面复制（D3D11 / DXGI）调用，只负责把像素交出来。
