# 局域网调参

入口：控制 → 局域网调参。默认关闭；端口默认 17890，可在关闭时修改。

开启后选择与另一台电脑同网段的 IPv4 地址，复制完整链接，在另一台电脑的浏览器打开。页面与脚本通过 Qt 资源内置，不需要复制 HTML，也不需要联网下载依赖。主程序必须保持运行。多个网卡会显示多个地址；127.0.0.1 仅供本机查看。

## 可调整范围

- 每个已有热键配置的主、备用、开镜三套 PID：Kp/Ki/Kd、FF、死区半径、XY 轴死区、跟随补偿、输出限幅及分段。
- 瞄准控制器、准星找色、瞄准热键屏蔽、X/Y 轴屏蔽、FOV 与动态 FOV 三参数。
- 默认瞄点，以及已有类别各自的 X/Y 瞄点范围和最低置信度。
- 当前生效热键分组、识别置信度、NMS、小目标增强。
- 准星取样宽高、最小像素数、闭合滤波半径，以及已有颜色的开关和 H/S/V 上下限。

网页按分组筛选配置，可搜索参数并使用数字框旁的加减按钮微调。编辑配置或备用/开镜参数不会自动选择该参数档。建立/删除热键、修改键位、增删颜色与类别、编排宏、硬件连接、采集和模型切换仍在本机操作。

## 生效与保存

修改先保留在网页中，点击“应用并保存”后才整体校验、写入当前配置文件并发布运行参数，本机界面随后同步。服务不自动开始推理、不模拟按键。页面显示的配置名是本机当前配置文件名。

无未保存修改时每 2.5 秒读取最新参数，编辑数字框时避免刷新抢走焦点。若本机或其他浏览器修改了调参内容，旧页面提交会返回冲突，保留网页修改并提示重新读取。点击重新读取会提示丢弃未应用修改。网络超时可能发生在服务器已经保存之后，因此不要自动重试；先重新读取确认结果。

## 访问与关闭

每次开启生成新的 256 位随机访问凭据，放在完整链接的 `#` 后。网页在当前标签页会话中保存凭据，API 用 Authorization 请求头校验；不把凭据写入配置文件。所有参数读取和修改都需要凭据，关闭服务会断开连接并作废凭据。重新开启后需重新复制链接。页面无外部脚本，不允许跨站写入或被嵌入 iframe。

HTTP 服务用于可信局域网，未提供公网 TLS。不要把链接转发给不希望允许调参的人。若 Windows 弹出防火墙提示，允许专用网络访问即可；程序不修改防火墙规则，也不做路由端口映射。

请求头限制 8 KiB、JSON 请求体限制 64 KiB、连接超时 5 秒，最多同时处理 24 个连接。网页和 API 均不提供文件浏览、任意配置键写入或远程命令执行。

本轮按用户此前要求只编译，不启动主程序或执行自动测试；跨电脑访问和实际调参效果待用户验证。
