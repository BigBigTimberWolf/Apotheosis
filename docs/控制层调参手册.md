# 2026-10-03 更新

FF 保留跟踪器已有的速度平滑与反向门控，去掉 8146270 新增的末端 15Hz 滤波。跟随补偿保护直接使用本次 PID 的真实限幅状态，轴屏蔽、自由死区和配置跳过输出时不会错误地报告饱和。此次不改 P/I/D 的既有计算。

“瞄准控制器 → FF 自动标定”使用现有检测框，对一个静止目标做小幅往返移动，按成功发送反馈拟合 X/Y 像素/计数和响应延迟。选择默认、第二套或开镜独立参数，手动保持对应倍率；点击开始，再按住所选热键约 6 秒。标定期间暂停普通瞄准和自动扳机，不要走位、开火或移动真实鼠标。松开热键中止未完成的标定；完成后松开热键，查看误差并点击应用。目标丢失、多个候选、倍率变化、发送失败、超时或数据不稳定时不应用结果。

三套参数独立保存换算和延迟；旧配置继续使用 0.91 与旧事件窗口，直到手动修改或成功标定并应用。标定后使用完整帧区间匹配历史发送事件，小位移不再按旧经验权重缩小。正常跟踪不运行标定拟合或背景观测，也不增加等待。灵敏度、采集尺寸或倍率变化后请重新标定；测得的延迟受采集帧间隔限制，标定不能消除采集链本身的延迟。

跟随补偿仍按原始误差学习；越过瞄点保留补偿，跟踪器确认反向或突然停止后清空对应轴。以下较早文档涉及背景辅助、冻结 PID 和固定换算的说明按历史版本阅读。

# 跟随补偿调参

当前只使用原 PID 加 X/Y 独立的跟随补偿。两个参数都在对应轴的“死区半径”下面；每个热键的默认参数和开镜独立参数都支持。

## 同按键热键的整套配置切换

左侧热键组选项同时决定当前运行组。在同一个热键组中新建两套热键，例如“步枪”和“狙”，都绑定鼠标右键。检测到相同的触发按键后，“触发按键”卡片会显示“激活当前热键”按钮，以及这套热键自己的激活快捷键。比如给步枪设置键盘 1，给狙设置键盘 2。

点击按钮或按激活快捷键后，右键使用所选热键的全部设置，包括识别类别和优先级、瞄准参数、FOV、找色、扳机、轨迹等。激活不等于自动按住瞄准键；可以在不按右键时提前选择，松开选择键或右键后仍保留选择。列表会标明“已激活”，选择会随配置保存，排序时跟随对应热键。

只有同组、相同完整绑定之间互斥；组合键不因包含某个普通键而被视为相同绑定，组合键仍优先。未手动选择的冲突项沿用原来的列表顺序优先级。激活键不能与同组任何触发键相同，也不能与同按键配置的另一激活键重复；界面会显示不可用原因。每套热键的激活键独立配置，不要求必须配齐一对。

原弹窗只保留“开镜独立参数”。旧配置中已有实际差异的第二套瞄准/独立扳机参数会迁移为同组下的“原名称 · 备用”热键，保留原主/备用选择键；新字段 `activation_key` / `activation_selected` 写入后不会重复迁移。

NET 使用盒子的物理键鼠上报读取激活键。监听需能独占本机 UDP 10000 端口，端口绑定失败会记录错误；未收到完整报告时不会伪装成正常的全松开状态，短包不更新状态，重启监听会清除旧状态。已通过本机 UDP 模拟盒子的 1/2 切换、右键触发、按键释放、短包及监听重启回归，仍需用户盒子实机验证。

## 参数含义

### 轴屏蔽与动态 FOV

FOV 的水平、垂直直径下方新增“屏蔽 X 轴”和“屏蔽 Y 轴”。勾选后停止该轴自动瞄准输出，主参数、备用参数、开镜参数共用当前热键的屏蔽设置。该轴 PID 积分、整数余量和跟随补偿会清除，路径曲线之后再次屏蔽输出，切换时清除旧移动队列。物理鼠标操作及扳机不由这两个选项屏蔽。

动态 FOV 现在只有三个数值参数，原“收敛强度”已移除：

- 缩小后的 FOV 大小：检测像素直径，1～4096px，默认 40px；每轴不超过该轴原 FOV。
- 缩小时间：0～2000ms，默认 200ms；越小越快，0 立即缩小。
- 放大时间：0～2000ms，默认 120ms；目标拉远或丢失后按此时间放大，0 立即放大。

距离固定时，约在设置时间内完成 95% 的尺寸变化。追近后收缩到用户设置的直径；尚未追近时按目标与准星的距离保留额外空间，不只按时间强行缩圈。原有强度依赖目标框尺寸，无法换算成固定像素直径，因此不自动转换；缺少新键时使用上述默认值。新配置键为 `dynamic_fov_size`、`dynamic_fov_shrink_ms`、`dynamic_fov_expand_ms`。

动态 FOV 已接入实际选框：原始 FOV 为以准星为中心的椭圆，以目标框与椭圆相交判断入圈。收缩限制新候选，不会仅因缩圈切断已锁定目标；既有目标仍须在原始 FOV 范围内。丢失目标按放大时间恢复，重新获取新目标保留当前圈大小，避免转火时突然放大；释放瞄准或硬重置恢复原尺寸。放大时间不是禁止转火的等待时间，目标进入当前圈后即可被选中，例如设置 500ms 不要求满 500ms 才能转火。预览中橙色为基础 FOV，浅蓝色为实际 FOV；回放逐帧保存并显示实际 FOV 与轴屏蔽状态，不使用当前界面参数。

采集端原先强制开启的圆形黑边遮罩已关闭，旧配置中的 `circle_mask=true` 也不再强制遮黑。预览恢复完整矩形画面；因原遮罩作用于共享采集图，送入检测器的图像也恢复完整角落。FOV 选框逻辑和预览圈线保留。

### 持续扳机的丢失延迟

在扳机流程「05 · 执行开火」设置「丢失续扳 ms」，范围 0～2000ms，默认 100ms，0 表示立即停止。配置键为 `trigger_loss_delay_ms`，旧配置缺少此项时也使用 100ms。

仅按住时长为 0 且未启用 3-1 切枪时生效：已经按下左键后，目标丢失或检测暂时中断，继续保持到延迟结束；连续丢帧不会刷新截止时间。延迟内重新发现命中区内目标，继续原长按。期间保留已按住的自动开镜，到时一起释放，不在无目标时启动新的一枪。目标仍可见但离开命中区、松开热键、停用扳机或切换热键时立即停止。单发和 3-1 切枪不受此延迟影响。

- 跟随补偿范围 0～50，默认 0，步长 0.1。
- 0 关闭该轴补偿，使用原瞄点。
- 数值越大，持续偏差的补偿建立越快；不是预测帧数，也不是直接增加 Kp。
- 原来的提前帧数和鼠标输出外推方案已移除。旧提前帧数不会自动转换为新强度，已有 PID/FF 参数保留。

先保留已经调好的 PID 参数，只小幅增加需要补偿的轴。该补偿需要观察持续偏差；确认运动事件后可短暂加快建立，再恢复普通积累。数值过大仍可能导致过冲，不能保证任意强度都稳定。

## 行为

普通补偿积累读取原瞄点与准星的偏差。首次建立等待为 30ms；较大偏差使用更短的估计与输出平滑（最低 25ms）。误差正在快速缩小时减少继续积累。额外的变向/急停判断读取连续图像位置变化与现有移动反馈，使用未被 FF 低速门槛归零的独立运动估计；不改变原 PID/FF 算法。

已取消原瞄点附近 1～4 像素停止积累的门槛，也彻底取消“原误差换边就清空补偿”。允许越过原瞄点，不要求补偿只能追到零误差；反向误差只参与正常的平滑积分，不触发硬清零。外推后的完整瞄点仍交给原 PID。

移除小误差停止门槛后，定位的小幅偏差也会继续积累。本轮只做编译，实际抖动和跟随效果仍由用户实测。

运动估计确认变向后，会优先利用最近稳定跟随时记住的补偿量，按新旧速度比例给新方向一个保守初值，再继续微调。初值经过短平滑，不是无条件把旧补偿反号；稳定记忆不足时，回退到有预算限制的短暂积累加速。预置和额外加速不会同时叠加，没有新增调参项。

快速积累也覆盖确认起步和同向明显加速。它不直接塞入一个提前量，而是在现有值上先快后慢地积累：理论倍率从最高 4 倍按 80ms 时间常数衰减，240ms 后恢复普通速度；误差波动、追近速度和有限额外额度会进一步降低实际倍率。方向确认后最多等待 250ms，让原始误差与新方向一致，再开始加速；同向加速需至少 3 张图像、持续 30ms，并有 500ms 触发间隔。静止误差本身不能触发这段额外加速。快速阶段额外增加量最多为“启动时平滑误差幅度与变向前补偿一半的较大值”，且不超过对应轴画面尺寸的 1/8；普通积累仍可继续增加。以上为本版内部试调值，实际效果待实机比较。

变向至少需要连续 3 张图像确认，低速时延长确认时间；急停也必须持续有接近零的运动证据，低速时允许更长零样本间隔。速度偶尔为零、减速和原误差换边都不会单独清空补偿。补偿保留独立平滑、幅度限制和饱和保护；丢失、换目标、切参数档和长图像间隔仍重置。运动估计使用经验鼠标比例，仍可能误判；不能保证各种速度都能立即“焊死”。

补偿学习范围和幅度均不再受目标框尺寸限制。最大新增偏移改为对应轴检测画面尺寸的一半，例如 416px 画面可到 ±208px，窄框不会把补偿卡在个位数。强度改变建立速度；较低 Kp 下仍可能存在补偿不足，较大偏移也需要实测是否过冲。

## 预览核对

- `Follow gain X/Y`：控制器当前真正使用的两轴补偿强度。
- `Shift(px) X/Y`：实际加到瞄点上的偏移（跟随补偿加 Smith 补偿，宏预测也计入），单位为检测画面的像素。
- `Base err(px) X/Y`：原始瞄点相对准星的误差，可据此比较补偿前后的跟随距离。
- `Motion(est) X/Y`：运动速度的经验估计；不是校准后的真实目标速度。
- `Follow X/Y`：LEARN 普通积累，BURST 正在额外快速积累，CHECK 正在确认方向，READY 已记住稳定补偿，SEED 已快速预置，TURN 确认变向但未预置，STOP 确认急停，UNKNOWN 运动证据不足。BURST 仅在该帧实际额外增加补偿时显示，预览和新录制回放均可见。
- `Seed(px) X/Y`：本次快速预置的初值。SEED 等事件保留显示 250ms；实际应用量以 Shift 为准。
- 青色十字为原瞄点，橙色圆为交给 PID 的补偿瞄点；跟随补偿关闭且没有 Smith 补偿（见下节）时重合，仅画橙色圆。状态行标明当前热键的默认或开镜参数。

强度非零但偏移一直为零，说明尚未建立补偿；偏移非零而原始误差仍大，说明补偿已介入但效果不足。不要把橙色虚拟瞄点到准星的距离当成真实目标误差。

回放也显示上述数据、两种瞄点及当时的参数档位。数据保存在每个录制帧中，回放不会读取当前调参值或实时预览状态；`PID err` 是补偿瞄点误差，`Base err` 才是原始瞄点误差。新版启动后需重新录制。

本轮按用户要求只编译，没有运行测试或实机验证。

## Smith 在途补偿与移动目标

FF 自动标定得到「响应延迟」（不小于 0）后，控制器启用 Smith 预测：已经发出、但检测画面里还没体现的鼠标移动（在途移动）先从 PID 误差里扣掉，所以静止目标不容易冲过头。延迟未标定（−1）时这套逻辑整体不启用。

只扣不补有个副作用：目标自己在这段延迟里也走了「速度 × 延迟」，全部扣掉会让准星一直落后这么多，橙色瞄点也被一并抵消。因此控制器把「目标自己的走动能解释的那部分」补回瞄点（Smith 补偿），只扣解释不了的部分。每个轴取下面三个量里最小的一个，且三者方向必须一致，否则不补：

- 目标速度 × 响应延迟；
- 最近约 120ms 持续存在的在途移动（刚开始的一次大幅对准动作不算目标在动）；
- 当前的在途移动（补偿不会超过它）。

效果：

- 静止目标、测速噪声、刚开始的大幅对准动作：补偿为 0，Smith 保持完整作用。
- 目标匀速移动：补偿约等于「速度 × 延迟」，橙色瞄点重新领先于青色十字（跟随补偿为 0 也会出现），准星落后量回到没有 Smith 时的水平。
- 目标急停：补偿随速度测量衰减（滤波 50ms），停稳后为 0；但急停时会冲过目标约「速度 × 延迟」，与没有 Smith 时相同。此前只扣不补时几乎不冲过头，那是用「一直落后」换来的。
- 速度滤波 50ms、在途滤波 120ms 是内部固定值，没有新增调参项；PID 公式、FF 和跟随补偿都没有改动，跟随补偿仍只学习剩下的偏差。
- 宏的「预测 ms」保持原含义，落点与 Smith 关闭时相同。若曾为抵消 Smith 的落后把它设成响应延迟值，现在应改回 0，否则会多外推一次。

以上数字来自模拟（纯延迟、效果即时生效的理想靶场），只用于比较方案，实机效果以实测为准。

## XY 轴死区（自由死区）

“死区半径”只是把死区内的输出按比例减弱，准星仍会被缓慢拉向瞄点。**XY 轴死区**是另一个独立参数：误差落在该像素范围内时，**该轴完全不输出**（PID、前馈和小数余量都清零，积分也会衰减归零），准星可以在里面自由晃动。

- X、Y 各自独立判断，所以 X 已进入范围、Y 还没进入时，只有 Y 继续修正。
- 数值为 0 表示关闭，此时行为与没有这项参数完全一致；“死区半径”本身没有任何改动。
- 边界本身（误差恰好等于该数值）算作区内。
- 自动扳机的“死区绕过”规则只绕过“死区半径”，**不会**绕过 XY 轴死区。
- 默认档、备用档、开镜档各自独立，位于对应轴的“死区半径”下面；局域网调参页也有同名项。
