# 当前方案：X/Y 跟随补偿与短时快速建立

2026-09-28。替换已被实测否定的“自身输出 + 卡尔曼 + 提前帧数”方案。原 PID/FF 公式保持不变，本轮按用户要求仅编译，不运行自动测试。

## 数据流

原瞄点误差 → 持续偏差估计 → 有界积分偏移（运动事件后短时加速）→ 平滑后的补偿瞄点 → 原 PID。

普通积累只读取原瞄点误差。变向、急停判断和有条件的补偿预置另读未取整的目标框观测中心及现有成功移动反馈；原 PID/FF 算法不变。运动估计沿用 FF 的经验比例：`(本次观测中心-上次观测中心+0.91*加权移动反馈)/图像间隔`，但不套用 FF 的低速归零门槛。它不是经过标定的目标真实速度，鼠标响应或时间对齐偏差仍会影响判断，也会引入反馈耦合。

## X/Y 独立状态与控制

配置为 followX/followY，范围 0～50，默认 0。界面在对应轴死区半径下一行，三组参数独立读写。关闭某轴时立即清除该轴偏移；正常调强度不改变原 PID 的积分、D 历史和整数余量。

时间戳相同或更早的图像不会重复积累偏差。没有图像时间戳才使用控制 dt；超过 200ms 的有效图像间隔重新建立状态。单次积分 dt 上限 50ms，避免把长空档全部当作已知持续误差。

## 更新规则

- 依据波动估计取参考噪声尺度 `clamp(1.5*variation,1,4)` 像素，仅用于自适应平滑和额外加速权重，不作为停止积累或反向清空门槛。原始偏差在噪声附近保持 80ms 平滑；偏差较大时逐渐缩短到 25ms，并估计波动。
- 首次平滑均值同向持续至少 30ms 后建立补偿。不使用框尺寸限制学习范围或补偿幅度，窄目标也可需要较大的提前偏移。
- 同向计时使用均值，不要求每次原始误差都同号，避免整数坐标的 0/1px 跳动反复清空计时。
- 原瞄点误差正在缩小时降低积累速度，误差增大时不施加收敛惩罚：`closingRate=max(0,-direction*(mean-prevMean)/dt)`，`signal=max(0.75,abs(mean))`，`confidence=signal/(signal+variation+0.15*closingRate)`。
- 按用户要求取消原瞄点附近的停止门槛、均值的 0.25px 方向死带及积分前扣除噪声带的处理。原始误差刚到零或跨过原瞄点时，完整的平滑均值仍参与积累；误差反号只改变普通积分趋势，不触发补偿清零。允许越过原瞄点，没有必须停在零误差的约束。
- 积累速度为 `0.25 * 跟随补偿强度 * confidence * 完整平滑误差均值`，按秒积分；数值改变的是建立速度。非零小偏差和检测偏置也会参与积累。
- 已删除“原误差跨过两倍参考噪声带即清零”的路径。现在只有运动估计确认变向或急停，才清除旧方向补偿；误差大小、符号不参与该事件判据。普通关闭、丢失、换目标和图像长间隔重置仍保留。
- 确认起步、确认变向但未成功预置，或确认同向明显加速时，允许一次先快后慢的快速积累。触发后最多等待 250ms，要求原始误差、平滑误差、原始速度和平滑速度与确认运动方向一致，误差超过参考噪声带、无待确认反向且未饱和；不由误差单独触发。原始速度需超过 0.5px/s 且不低于平滑速度幅度的 50%。条件不满足时保留普通积分，快速窗口照常流逝。
- 快速阶段持续 240ms，额外倍率为 `3*exp(-t/0.08)`，按图像区间解析积分取平均，再乘参考噪声响应和 confidence；因此理论总倍率最高为 4 倍，之后衰减回正常速度。额外预算为 `min(画面尺寸/8, max(启动时abs(mean), 变向前补偿幅度/2))`；起步和同向加速不使用旧补偿预算。仅限制额外增加的量，普通积分和总半画面限幅不变，不预置偏移，也不因原误差换边清零。
- 同向加速需已有 120ms 同向运动；平滑速度超过近期参考速度的 1.3 倍，差值大于 `max(2,2*速度不确定性)`，原始速度同向且不低于平滑速度的 85%；至少 3 张图像、持续 30ms 后触发。每次加速触发后的 500ms 内不再触发同向加速，恒定速度不反复启动。确认变向可独立重建；预置成功时不叠加额外加速。运动证据缺失、关闭、重置或修改强度会取消尚未完成的加速。
- 存储偏移上限为对应轴检测画面尺寸的一半，例如 416px 画面对应 ±208px。控制器传入画面尺寸，不再传入目标框宽高。原输出已经同向饱和时暂停继续积累，仍允许回收。强度控制建立速度，不能保证任何原 PID 参数下都消除偏差。
- 普通补偿在噪声附近以 60ms 时间常数平滑，较大均值偏差时逐渐缩短到 25ms；确认运动变向时旧的平滑值立即清零。预置成功后的前 100ms 使用 15ms 时间常数快速应用初值。重复图像只推进已有偏移的平滑，不能确认运动事件。清零及快速预置仍会改变 PID 输入，非零 D 也会响应，需实测。

## 运动确认与补偿预置

- X/Y 独立。速度均值用 40ms 平滑，波动用 120ms 平滑。方向可信门槛为 `max(0.5,0.5*波动*sqrt(min(dt/0.12,1)))`，单位为估算像素/秒；不将低速剪成 FF 的零速度。
- 新方向需至少 3 张新图像，原始速度与平滑速度同号且均超过方向可信门槛，持续时间为 `clamp(0.6/max(速度,1),0.025,0.18)` 秒；旧方向还需持续至少 120ms 才触发变向清零。中低速保留更长确认时间，单帧反号及其滤波残留不清零。
- 急停要求已有至少 250ms 同向运动，原始速度连续小于 0.5，且平滑速度低于 `max(0.5,0.05*近期速度)`。确认时长为 `clamp(1.5/max(近期速度,1),0.12,1.5)` 秒；低速下允许更长的量化零样本间隔。短暂零值、证据缺失、仍有非零速度的减速不直接触发急停。极低速与噪声仍可能不可分辨，不承诺可靠识别所有速度。
- 稳定运动至少 250ms、补偿沿运动方向且幅度至少 1px、无输出饱和，补偿变化率不超过 `max(2,0.25*幅度)` px/s，存储值与应用值之差不超过 `max(1,0.1*幅度)` px，速度偏离近期速度不超过 `max(1,0.25*近期速度)` 且超过两倍方向可信门槛。以上连续满足 200ms 后记录补偿量和速度。
- 确认反向时，稳定记忆需在 500ms 内；本次原始速度与新方向一致且不低于平滑速度的 75%，新旧速度比在 0.25～2 内且未饱和，才预置新方向补偿。幅度为 `旧稳定幅度*0.8*min(新旧速度比,1.25)`，同时受半画面限幅约束。一次变向消耗一次记忆，不反复翻转旧值。
- 没有稳定记忆或证据不足时保留普通积累路径；运动证据缺失会使记忆失效，但不会清除已有补偿。强度变化使预置记忆、短暂加速失效，不清除已有普通补偿。没有新增界面参数。

这些是内部经验参数，不是实机验证后的最优值，也不声称能精确识别静止、目标加速度或传输延迟。模型持续偏置、未知硬件响应、发送故障或大强度仍可能产生错误补偿。

## 保留与移除

保留：原 PID/FF、死区、限幅、分段和整数余量规则；回放显示实际补偿瞄点。预览增加原瞄点青色十字、补偿瞄点橙色圆和两点连线；显示当前生效的 X/Y 强度、实际偏移像素、原瞄点偏差与参数档位，数据来自同一次控制输出。

移除：AimpointPredictor、PredictionMotionHistory、额外成功移动累计接口、提前帧数 UI/配置写回。原 FF 的 MotionFeedbackWindow 及成功运动事件不变。

新配置键：recovered_pid_follow_x/y、recovered_secondary_pid_follow_x/y、recovered_scope_pid_follow_x/y。旧提前帧数不迁移为补偿强度，旧配置载入时新参数为 0。

ReplayFrame 逐帧保存原始锚点、补偿后锚点、生效强度、参数档位，以及运动估计、预置幅度和判断状态。预览与回放显示 `Motion(est)`、`Follow X/Y`、`Seed(px)`：CHECK 确认中、TURN 确认变向、STOP 确认急停、SEED 已预置、READY 有近期稳定记忆、LEARN 普通积累、UNKNOWN 运动证据不可用；追加 BURST 表示本帧实际额外快速积累，保留旧状态编号。预置等事件显示 250ms，BURST 按实际参与额外积累的帧显示；预置数值是当次初值，实际应用量仍看 Shift。所有回放值取自录制帧；不读取当前参数或实时叠加状态。
