# 导入其他项目的 .xmcurve 轨迹

`.xmcurve` 是另一个项目导出的**真人鼠标轨迹数据集**（不是网络权重）。本项目没有那个项目的源码，格式是从实际导出文件反推出来的，导入后用**本项目自己的训练器**训练出本项目的神经曲线，所以可以直接使用。

## 怎么用

1. 在瞄准设置的“神经网络训练曲线”区域点 **导入神经曲线**，选择 `.xmcurve` 文件（也可以在“录制轨迹并训练神经网络”弹窗里点 **导入 .xmcurve 轨迹…**）。
2. 弹窗会在后台读取文件并立即训练，状态栏显示导入了多少条，下方显示曲线预览和拟合质量。
3. 满意后点 **应用到当前热键**，才会写入当前热键；不满意直接关闭，不会改任何配置。
4. 导入的轨迹可以和你自己录制的轨迹放在一起训练：先导入，再勾选“追加到本窗口已有轨迹”继续录制。录制的“最近 200 条”窗口只作用于录制的部分，不会把导入的轨迹挤掉。

## 导入时做了什么

- 每个样本是一笔从起点拖到目标的轨迹。文件里的坐标是“屏幕位置 ÷ 录制时画布的像素尺寸”，但文件**没有写画布尺寸**。好在每个坐标都是整数像素，所以程序从数据里反推出画布尺寸（按录制会话分别反推，中途改过窗口大小也没关系），再还原成等比例的像素坐标。
- 还原后的轨迹和你在本项目画布上录制的轨迹走**同一个归一化函数**（`boss::normalizeNeuralStroke`）：起点到目标连线为基准，记录“沿线进度”和“偏离直线的比例”，起点和终点偏离固定为 0，重采样到 256 点。通过同样的校验才会被采用：起点到目标至少 50 像素、绕行不超过直线的 4 倍、必须到达目标圈。
- 目标圈半径取文件里的相对半径乘以画布较短边（实测等于 0.035×420 = 14.7 像素，和本项目画布的 15 像素一致）。
- 样本超过 3000 条时会均匀抽样，避免训练耗时随条数平方增长。

## 实测

用一份真实导出文件验证（1507 条，画布还原为 1043×420）：全部通过校验，读取约 0.2 秒、训练约 0.2 秒，验证偏差约 3.1%（同一验证集上全直线基线约 4.4%），最大弯曲约 4.3% 路径长度，曲线很平缓，符合自然手势的轻微弧度。

## 限制

- 只验证过 **版本 4** 的数据布局，其它版本会明确提示不支持，不会硬猜。
- 本项目的神经曲线只有一条整体曲线（只和进度有关），**不区分方向和距离**。文件里按 8 个方向 × 3 档距离记录的分档信息在导入时不使用，所有方向、距离的轨迹按左右镜像对齐后合成一条典型曲线。
- 评估的是“曲线拟合一致性”，不代表游戏里的命中率。
- 文件只被当作数据读取（JSON），所有字段都会校验和限幅，不会运行任何内容。
